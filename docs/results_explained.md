观察与边界：

1. 任务状态修复与写回防护是两件事。初次修对后，旧摘要仍能在无门禁条件下回流。
2. 低预算下严格核验会牺牲可回答比例，正确率未必优于保留旧状态的简单方法；报告保留了这一负面结果。
3. 同值有效工作可继续保留，固定任务集合上的全量重规划则会重做这些工作。
4. 旧摘要是人为设置且所有方法共享的压力输入，不是测得的真实模型失误概率。
5. 没有真实模型、自由文本语义核验或缓存计量结果，不据此宣称通用 Agent 优势。
