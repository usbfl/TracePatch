# v0.2 已知局限

- CPU 离线、结构化合成场景；任务角色与摘要模板受控，没有验证自由文本 Agent。
- 新版执行器只操作可观察的状态与固定四任务计划，不代表 LLM 内部推理过程，也不做模型权重编辑。
- 单次可信 CORRECTION；时间变化和范围并存保留边界测试，未纳入主矩阵。
- 长期修复支持证据丢失返回 UNKNOWN；新版主 smoke 未系统扫证据丢失率。文本相似并非因果证据。
- 旧摘要重放是确定性的压力条件，不代表真实模型产生旧摘要的自然发生率；无门禁对照可能被该压力主导。
- 写回检查依赖结构化版本绑定与当前证书，不能语义验证任意自由文本；拒绝无证据写入会损失可用性。
- 上下文整理只测消息字符与脚本读取，不测真实 token、服务缓存、KV Cache 编辑或价格。
- 新版用途调度是显式优先级启发式，尚未学习或校准风险与成本；未实现自主 Agentic RAG。
- 三轮连续写回是真实执行的离线闭环，但下一任务使用确定性动作规则；真实服务调用为 0。
- SQLite 采用每事件原子快照，较大图会增加 I/O；单进程日志与哈希用于可复现和防误修改，不是多写入者并发系统或对恶意 Python 的安全沙箱。
- 尚未接入 GameReach、memory-rollback 作者基准或 LongMemEval，不能视为这些系统的复现。
- Linux/Python 3.12 实机验证；PowerShell、macOS 命令未在相应系统实跑。
- 历史 v0.1 文档移入 docs/v0.1_archive；其历史实验计数不代表本版重新验证。
