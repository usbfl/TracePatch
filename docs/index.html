这是确定性执行器上的离线研究原型。真实 LLM Agent 的自主续做能力尚未验证；报告中的条件运行数不等于独立样本数。

从更正到继续使用

01 / 找到影响

确定更正的范围和关联内容

结合可见依赖、文本候选与当前任务用途定位可能受影响的判断，兼顾缺失依赖的情况。

02 / 按预算核验

读证据，再更新结论和计划

核对来源与适用范围，保留有效工作，重新打开失效步骤；记录预算、事件和恢复检查点。

03 / 检查再次写回

防止旧错误回到下一轮

检查摘要声明的版本、值、主体、范围和时间，并在三轮写回与检索中观察错误是否再次传播。

本次报告的实验规模

8独立基础场景
576正式 test 条件运行
6对比方法

576 = 8 场景 × 2 缺边率 × 3 预算 × 2 当前用途 × 6 方法。每次执行三轮；指标按基础场景聚合。另有 12 次固定演示与 144 次 dev 运行。

复现一个离线演示

Python 3.11+、SQLite、标准库即可运行；无需 API Key。

git clone https://github.com/usbfl/TracePatch.git
cd TracePatch
python -m tracepatch v2-demo --out runs/my_demo
# 打开 runs/my_demo/dev/report.html

GitHub 仓库保留源码、测试、配置和精选 HTML 报告；完整 SQLite 轨迹与检查点在本地运行后生成。
