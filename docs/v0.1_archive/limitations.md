# 已知局限与未执行事项

- 数据是虚构设备/软件资格的合成结构化声明；核心 DAG 模式共享，随机扩展节点以 COPY 为主。即使有置信区间，也不能代表真实 Agent 任务总体。
- 离线提取读取真实文件内容，但仅支持受控 FIELD 模板。未执行真实模型调用，未证明自由文本端到端纠错能力。
- 原始 capsule 必须本来存在；真正丢失会返回 UNKNOWN。候选语义相近不能证明因果影响，TopK 也可能漏掉错误节点。
- 主实验只有一次已知可信 CORRECTION，主场景所有声明共享完整有效区间。TemporalStore 单独支持分段 UPDATE/CORRECTION 与不同 scope 共存，不宣称完整通用时态推理。
- 当前运行修复后只读评价，没有新写入，因此 stale_error_reuse 不是“修好后再污染”。
- 存储/版本动作与读取预留持久化；离线恢复通过重演控制流重建，计算开销不为零，账本不会再次收费。是单进程实验引擎，不支持多个进程同时写同一运行。
- live 在超时/连接结果不明确时采用保守 UNKNOWN，不重发。只能限制本地已授权尝试，不能保证服务商最终外部账单。
- 代码与协议哈希防止无意修改混用，不是对恶意改库者的密码学签名。Python 同进程隔离是接口契约，不是 OS 沙箱。
- 报告默认用自绘 SVG 而非必需 Matplotlib；曲线只连接实际预算采样点，不表示中间预算已测量。
- pilot（4,320 test 运行）、research、压力条件和完整消融的批量结果见 validation_report 的实际状态；配置可运行不等于已执行。
- Windows PowerShell/macOS 命令已提供；本次运行环境是 Linux/Python 3.12，其他操作系统未实机验收。
- 未接入 memory-rollback 作者基准、LongMemEval 或 GameReach；未进行正式学术查新完备性证明。
