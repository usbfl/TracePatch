# 研究协议 v0.1

研究问题是：显式依赖缺失、原始执行记录部分可恢复时，预算化核验调度能否改善持久记忆的只读复用？不要求 TracePatch 获胜。根错误的诊断、纠正指令真实性和开放域知识冲突不是本实验的研究变量。

## 单位、生成与隔离

独立实验单位为基础场景。固定核心 DAG 模式保证至少三个非根错误、三个根后代但仍正确的声明、三个无关正确声明、深度至少二的错误链，以及完整独立 OR 支持。随机部分包括命名实体、根设备、数值阈值、填充节点的依赖、历史使用及查询。按构造保证约束，并在生成器内断言检查；本版不靠“挑出有利场景”重采样，`attempts=1`。核心图模式共享使任务多样性有限。

根选择、图结构、标识、缺边、丢失、潜在使用权重、过去访问、未来查询均采用独立 SHA-256 派生随机流。高缺边率使用相同每边随机数形成嵌套掩码。capsule 丢失与掩码、错误标签独立。dev/test 按基础场景、用户、命名实体拆分；通用中文表达/规则模式共享。公开 ID 为不透明稳定随机标识。

`public` 包含初始声明、G_obs、已知更正、历史访问与粗略 capsule 大小。`environment` 包含执行配方、当时版本/值轨迹、原文绑定与正文。`evaluation` 包含 G_true、真值、未来查询、潜在权重和生成参数。修复器/核验器不 import evaluator。删掉 evaluation 仍可完成修复，改变未来查询或 gold 不改变动作。调度器仅接收 K、权重和公开视图；不能利用生成种子重建隐藏数据。

## 处理协议

除 root_only，所有方法先隔离当前可见后继。full_scan 不预先隔离全部无关记录。expanded_fifo 与 tracepatch 的初始候选严格一致。语义候选只选一次：NFKC+casefold 字符 3-gram TF-IDF cosine，与实体 Jaccard 按 0.6/0.4 加权，空向量为 0。s 值固定；相似度仅发现候选，不能生成影响边或直接判错。

`g=0.8^(d-1)`，`r=max(g,0.7*s)`，`u=log(1+count)/log(1+max_count)`，全无历史则 u=1。`c_hat=max(1,ceil(hint/2048))+1+尚未认证的可见直接前驱数`。`P=r*(0.25+0.75*u)/max(1,c_hat)`。并列按创建时间与 ID。hint 不是收费依据；风险不是校准概率。恢复边后动态扩展可见后继，但不重复撤回已有有效证书。

核验按 capsule 固定输入顺序递归。AND/OR 使用三值短路；未知输入仍可被另一完整决定性分支覆盖。事实必须读原文并提取，不能把旧 ACTIVE 或生成轨迹值当支持。有限规则不执行任意代码。循环、非法类型、超长内容和深度超限转为 UNKNOWN。直接根更正由可信证书提供，旧版本绑定解析到当前更正。

已知结果以事务写后继版本；即使值未变也绑定新证书。旧版本 SUPERSEDED，UNKNOWN 为 QUARANTINED 并保留原因。查询仅返回相容 ACTIVE 版本或 ABSTAIN，不读证据、不修复。没有后续写入阶段。

## 成本与恢复

读取 capsule/原文块按实际 UTF-8 字节 `max(1,ceil(bytes/2048))`；不存在读取为 1；新叶提取与规则执行各 1。缓存命中 0，但计逻辑请求。缺失/损坏文件在返回内容前明确失败。跨方法、预算、场景不共享逻辑缓存。

根更正、检索、图遍历不计核验单位，单列操作/记录数、墙钟时间。全部方法共享全局停止规则：下一原子操作无法预留时立即停止整个运行；不换目标找便宜操作。报告 planned、spent、reserved、读取、字节、执行、审计、缓存、模型、状态变更与时间。

SQLite 每个动作先 pending+reservation，再提交结果+收费。恢复重演确定性控制流，已提交动作只恢复输出；不会新增日志、逻辑请求或费用。故障测试分别中断已提交/待执行读取。网络发送结果不明时保留已用 API 配额，标记 uncertain，绝不自动重发。远程最终收费无法由本地精确控制。

## 评价

先冻结最终状态及哈希，再加载 gold。主集按独立抽样的未来使用分布，另有每节点一次的 uniform 集。先每场景算比例再跨场景平均。所有方法/条件共用基础场景 bootstrap 索引（1,000 次、固定 seed），输出均值与 95% percentile 区间、配对差分和样本量。smoke 不作统计显著性主张。失败/未运行数量可见；缺失指标为 NA，均值的 scored 数量明确列出，不把失败悄悄当正常样本。

| 指标 | 分母与语义 |
|---|---|
| overall_accuracy | 正确回答 / 全部问题，ABSTAIN 未正确 |
| coverage | 有回答 / 全部问题 |
| selective_accuracy | 正确 / 有回答；零分母 NA |
| stale_error_reuse | 初始错误且应变化的非根查询中仍回答旧错误值 / 该固定查询集合 |
| benign_unavailability | 初始正确节点中无正确 ACTIVE 后继的比例，包含仍正确后代 |
| global_wrong_active | 最终错误 ACTIVE 节点数 / 原节点数 |
| original_error_residual | 最终错误 ACTIVE ∩ 初始错误 / 初始错误数 |
| new_errors | 最终错误 ACTIVE − 初始错误的数量 |

另外输出根正确率、非根正确率/残留、正确恢复数、UNKNOWN 原因、候选召回与恢复边数。任何使用 gold 的诊断均在 evaluator 中，只用于冻结后解释，不反馈排序。物理删除数为零，不能替代正确记忆不可用率。

## 冻结与模式

test 必须提供 dev 后冻结的协议。协议包含方法/权重/K、预算/条件、语义模式、模型配置、源码 SHA-256、数据清单、特征/提示词/规则版本、指标/统计参数。钥匙只来自环境变量，不进入协议。模式 live/replay 都是 model 叶提取语义，输出目录与传输状态不进入语义哈希。replay 只读取通过冻结完整性检查的 live 源运行。

主 smoke 为 8 个 test 基础场景 × 2 缺边率 × 2 预算 × 5 方法 = 160。dev 同规模独立生成。pilot 和 research 的数量是预设，不是已执行结果。full_audit 以独立诊断配置输出，不混入预算排行榜。
